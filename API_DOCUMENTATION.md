# Fleet Monitoring Dashboard – API Documentation

## 1. Overview
The Fleet Monitoring Dashboard system simulates driver behavior events such as speeding, harsh braking, and drowsiness detection. 
These events are generated by a simulator and sent to the backend server through REST APIs.

The backend processes the events, stores them in a MySQL database, calculates violations and risk score, and sends real-time updates to the frontend dashboard using WebSocket.

The dashboard displays analytics such as:
- Total Trips
- Live Drivers
- Violations
- Risk Score
- Dashcam Feed

----------------------------------------------------

## 2. Base URL

http://localhost:5000

All API requests start with this base URL.

----------------------------------------------------

## 3. Technology Stack

Backend: Node.js, Express  
Database: MySQL  
Real-time Communication: WebSocket (ws library)  
Frontend: HTML, CSS, JavaScript  

----------------------------------------------------

## 4. API Endpoint

API Name: Create Driver Event

Endpoint:
POST /event

Description:
This API receives driver behavior events generated by the simulator.
It processes the event, stores it in the database, updates violation count,
and calculates risk score dynamically.

----------------------------------------------------

## 5. Request Body

Example JSON request:

{
  "type": "speeding",
  "speed": 95
}

Request Parameters:

type   → Type of driver event (speeding / braking / drowsy)
speed  → Current vehicle speed

----------------------------------------------------

## 6. Event Types

speeding  → Vehicle exceeds speed limit
braking   → Sudden or harsh braking detected
drowsy    → Driver fatigue or drowsiness alert

----------------------------------------------------

## 7. Example API Call

POST http://localhost:5000/event

Request Body Example:

{
  "type": "braking",
  "speed": 40
}

----------------------------------------------------

## 8. Response Example

{
  "trips": 1,
  "drivers": 3,
  "violations": 6,
  "riskScore": 60
}

Response Fields:

trips       → Total number of trips
drivers     → Number of active drivers
violations  → Total violations detected
riskScore   → Calculated risk score

----------------------------------------------------

## 9. Risk Score Calculation

Risk score is calculated dynamically based on the number of violations.

Formula:

Risk Score = Violations × 10

Example:

Violations = 5
Risk Score = 50

----------------------------------------------------

## 10. WebSocket Communication

The system uses WebSocket to send real-time updates from the backend to the frontend dashboard.

WebSocket URL:

ws://localhost:5000

Example WebSocket Data Sent to Frontend:

{
  "trips": 1,
  "drivers": 3,
  "violations": 8,
  "riskScore": 80
}

This allows the dashboard to update automatically without refreshing the page.

----------------------------------------------------

## 11. Database Information

Database Name:

fleetdb

Table Name:

----------------------------------------------------

## 12. Database Schema

Column Name   | Type         | Description
------------------------------------------------
id            | INT          | Event ID

speed         | INT          | Vehicle speed
created_at    | TIMESTAMP    | Event timestamp

----------------------------------------------------

## 13. Example SQL Query

SELECT * FROM driver_events;

----------------------------------------------------

## 14. System Workflow

1. Simulator generates driver events every 2–3 seconds.
2. Events are sent to the backend API using HTTP POST requests.
3. Backend processes the event and stores it in MySQL database.
4. Backend calculates violations and risk score.
5. WebSocket sends real-time updates to the frontend dashboard.
6. Dashboard updates automatically without refreshing.
